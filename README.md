# 📸 写真位置情報・自動仕分けツール (Exif GPS Sorter)

本ツールは、写真データに埋め込まれている撮影日時と位置情報（GPS）を読み取り、**「一定時間（デフォルト約10分）以上の経過」を基準に現場ごとのフォルダを自動作成し、写真を仕分け（コピー）**する業務効率化プログラムです。

さらに、緯度・経度から**詳細な住所（〇〇丁目など）や施設名（〇〇公園など）を自動取得し、フォルダ名として付与**するため、広範囲にわたる現地踏査（フィールドワーク）の記録や、大量の現場写真の整理を大幅に効率化できます。

## ✨ 主な機能
* **現場ごとの自動フォルダ作成:** 写真の撮影日時を解析し、時間間隔をもとに現場ごとのフォルダを自動作成して写真をコピーします（元の元本データはそのまま保持されます）。
* **詳細住所・施設名の自動取得:** 座標データから「〇〇県〇〇市〇〇町1丁目」といった詳細住所や、「〇〇公園」「〇〇市役所」などの施設名（POI）を自動取得し、フォルダ名に設定します。
* **簡易な操作性:** 解析対象となる大元の写真フォルダのパス（場所）を指定して実行するのみで処理が完了します。

## 📦 使用ライブラリ

本プログラムは、以下のPythonライブラリを使用して構築されています。

* **`Pillow` (PIL):**
  画像ファイルに付与されているExif（撮影日時、GPS座標等のメタデータ）を抽出するための画像処理ライブラリ。
* **`geopy`:**
  取得した緯度・経度を、OpenStreetMap等の地図データと連携させ、住所や施設名に逆ジオコーディング（テキスト化）するためのライブラリ。
* **Python標準モジュール (`os`, `shutil`, `datetime`, `re`):**
  ファイル操作、安全なデータコピー、日時の計算、およびフォルダ名禁則文字の処理等に使用。

## 🛠️ 事前準備（セットアップ）

初回実行時は、以下の手順で実行環境（仮想環境）を構築してください。

### 1. プログラムの取得
GitHubのリポジトリ画面右上にある緑色の **[<> Code]** ボタンより **[Download ZIP]** を選択し、任意の場所に保存・解凍します。その後、解凍したフォルダを **VS Code** 等のエディタで開きます。

### 2. 仮想環境の構築とライブラリのインストール
VS Codeのターミナルを開き、以下のコマンドを順に実行して環境を構築します。

```bash
# 1. 仮想環境の作成
python -m venv .venv

# 2. 仮想環境の有効化（Windows環境の場合）
.\.venv\Scripts\activate

# 3. 必須ライブラリの一括インストール
pip install -r requirements.txt
```

## 🚀 使い方（完全ガイド）

事前準備が完了次第、以下の手順で写真の自動仕分けを実行します。プログラムの改修は不要であり、対象フォルダのパスを指定するのみで処理が完了します。

### 📋 ステップ 1: プログラムファイルを開く
VS Codeのファイルエクスプローラーから sorter.ipynb を開きます。

### 💻 ステップ 2: カーネル（実行環境）を選択する
1. 画面右上の 「カーネルの選択 (Select Kernel)」 をクリックします。
2. 「Python 環境」 を選択し、手順2で作成した .venv を指定します。

### 📝 ステップ 3: 写真フォルダのパス（場所）を書き換える
sorter.ipynb の最下部にある「実行部分」のセルを確認し、FOLDER_PATH の記述を処理対象の写真フォルダのパスに書き換えます。

```python
# ==========================================
# 実行部分
# ==========================================
# ⚠️ この部分を、あなたが整理したい写真フォルダのパスに書き換えます
FOLDER_PATH = r"\\位置分析したい写真ファイルがあるフォルダのパス"
```


### ▶️ ステップ 4: プログラムの実行
パスの指定完了後、セルの左上にある ▶（再生ボタン） をクリック、または Shift + Enter キーを押下して実行します。
処理が完了すると、指定したフォルダ内に _現場別_自動仕分け という名称のフォルダが生成され、仕分け結果が保存されます。

## ⚠️ ご利用にあたっての注意
写真フォルダのパスの書き換えについて：
パスの先頭にある r と、前後を囲む "（ダブルクォーテーション）は削除せずに、内部の文字列のみを変更してください。

判定基準となる時間間隔を変更したい場合について：
実行部分の gap_minutes=10 の数値を任意の値に変更してください。

プライバシーについて：
自宅周辺など、公開されたくない場所で撮影した写真を扱う場合は、結果の取り扱いに十分ご注意ください。

位置情報がない写真：
カメラの設定でGPSがオフになっていた写真や、LINE等で転送されて位置情報が消えた写真は「位置情報がないファイル」として別枠でまとめて表示されます。

住所取得の制限について：
無料の地図データを使用しているため、連続で大量のエリアを検索すると一時的に取得エラーになる場合があります（サーバー保護のため、1回の検索ごとに1秒の待機時間を設けています）。
