# 📸 写真位置情報・自動仕分けツール (Exif GPS Sorter)

現場調査や旅行などで大量の写真を撮影した後に、「この写真、どの辺りで撮ったんだっけ…？」と整理に困ったことはありませんか？

このツールは、写真データに埋め込まれている位置情報（GPS）を読み取り、**近い場所（約300m四方）で撮影された写真同士を自動でグループ分け**してくれるプログラムです。さらに、緯度・経度から**大まかな住所を自動で割り出して表示**するため、土地勘がない場所の写真でも簡単に整理することができます。

河川や道路などの広範囲にわたる現地踏査（フィールドワーク）の記録や、大量の業務写真の整理などに非常に便利です。

## ✨ 主な機能
* **自動グループ化:** 写真の位置情報を解析し、約300m四方のエリアごとに分類します。
* **住所の自動取得:** 座標データから「〇〇県〇〇市〇〇町」といった推定住所を自動で取得し、画面に表示します。
* **簡単操作:** 解析したい写真が入っているフォルダを指定して実行するだけ！

---

## 📦 このツールで使っている主な部品（ライブラリ）

プログラミングをゼロから書くのは大変なので、このツールでは世界中のエンジニアが作った便利な「部品（ライブラリ）」を組み合わせて動かしています。

* **`Pillow` (PIL):**
  画像を開いたり、編集したりするための強力な画像処理ライブラリです。このツールでは、写真の裏側に隠れている「Exif（エグジフ）データ」という撮影時の情報から、GPSの数値を抜き出すために使っています。
* **`geopy`:**
  世界中の住所や座標を変換してくれる地図ライブラリです。このツールでは、写真から取り出した「緯度・経度」の数値を、OpenStreetMapという無料の地図サービスと連携して「〇〇県〇〇市〇〇町」といった人間にわかりやすい住所に翻訳するために使っています。
* **Pythonの標準機能 (`os`, `time`, `collections`):**
  追加インストール不要で最初から使える機能です。フォルダの中にある写真を順番に探したり、地図サーバーに負担をかけないよう住所を調べる間に「1秒休む」といった調整を行うために使っています。
