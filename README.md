# 📸 写真位置情報・自動仕分けツール (Exif GPS Sorter)

現場調査や旅行などで大量の写真を撮影した後に、「この写真、どの辺りで撮ったんだっけ…？」と整理に困ったことはありませんか？

このツールは、写真データに埋め込まれている位置情報（GPS）を読み取り、**近い場所（約300m四方）で撮影された写真同士を自動でグループ分け**してくれるプログラムです。さらに、緯度・経度から**大まかな住所を自動で割り出して表示**するため、土地勘がない場所の写真でも簡単に整理することができます。

河川や道路などの広範囲にわたる現地踏査（フィールドワーク）の記録や、大量の業務写真の整理などに非常に便利です。

## ✨ 主な機能
* **自動グループ化:** 写真の位置情報を解析し、約300m四方のエリアごとに分類します。
* **住所の自動取得:** 座標データから「〇〇県〇〇市〇〇町」といった推定住所を自動で取得し、画面に表示します。
* **簡単操作:** 解析したい写真が入っているフォルダを指定して実行するだけ！

---

## 📦 このツールで使っている主な部品（ライブラリ）

プログラミングをゼロから書くのは大変なので、このツールでは世界中のエンジニアが作った便利な「部品（ライブラリ）」を組み合わせて動かしています。

* **`Pillow` (PIL):**
  写真の裏側に隠れている「Exif（エグジフ）データ」という撮影時の情報から、GPSの数値を抜き出すための画像処理ライブラリです。
* **`geopy`:**
  写真から取り出した「緯度・経度」の数値を、無料の地図サービス（OpenStreetMap）と連携して「〇〇県〇〇市〇〇町」といった人間にわかりやすい住所に翻訳するためのライブラリです。

## 🛠️ 事前準備（セットアップ）

プログラミングに詳しくない方でも、以下の手順を順番になぞるだけで自分のパソコンに専用の実行環境を作ることができます。

### 1. プログラムのダウンロード
GitHubの画面右上にある緑色の **[<> Code]** ボタンをクリックし、**[Download ZIP]** を選んでパソコンに保存・解凍します。その後、解凍したフォルダを **VS Code** などのエディタで開きます。

### 2. 仮想環境の作成とライブラリのインストール
VS Codeのターミナル（画面下部の黒い画面）を開き、以下のコマンドを1行ずつコピー＆ペーストして `Enter` キーで実行します。

```bash
# 1. プログラムを動かすための専用の箱（仮想環境）を作成します
python -m venv .venv

# 2. その箱の中に入ります（有効化）※Windowsの場合
.\.venv\Scripts\activate

# 3. 必要な部品（ライブラリ）を全自動でまとめてインストールします
pip install -r requirements.txt
```

## 🚀 使い方（完全ガイド）

準備ができたら、いよいよ実際の写真を分類してみましょう！プログラムコードを新しく書く必要はありません。**パスを1箇所書き換えて、ボタンを押すだけ**です。

### 📋 ステップ 1: プログラムファイルを開く
VS Codeの左側のファイル一覧から **`sorter.ipynb`** をクリックして開きます。これが実行するプログラム本体です。

### 💻 ステップ 2: カーネル（実行環境）を選択する
1. 画面の右上にある **「カーネルの選択 (Select Kernel)」** をクリックします。
2. メニューから **「Python 環境」** を選び、先ほど作成した **`.venv`** （Python 3.13など）を選択します。これでプログラムを動かす準備が整いました。

### 📝 ステップ 3: 写真フォルダのパス（場所）を書き換える
開いた `sorter.ipynb` の画面を一番下までスクロールすると、以下のような「実行部分」のコード枠（セル）があります。

```python
# ==========================================
# 実行部分
# ==========================================
# ⚠️ この部分を、あなたが整理したい写真フォルダのパスに書き換えます
FOLDER_PATH = r"\\202.251.23.197\業務\26\PHOTO(ORG）現場写真記録\M17026023_滋賀国電通26\260701～0703_NW現地踏査 - コピー\※広瀬撮影（山本さんと同順）"
```

## ⚠️ ご利用にあたっての注意
プライバシーについて: 自宅周辺など、公開されたくない場所で撮影した写真を扱う場合は、結果の取り扱いに十分ご注意ください。

位置情報がない写真: カメラの設定でGPSがオフになっていた写真や、LINE等で転送されて位置情報が消えた写真は「位置情報がないファイル」として別枠でまとめて表示されます。

住所取得の制限について: 無料の地図データを使用しているため、連続で大量のエリアを検索すると一時的に取得エラーになる場合があります（サーバー保護のため、1回の検索ごとに1秒の待機時間を設けています）。
